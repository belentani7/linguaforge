# Mapa curricular LinguaForge A0–C2

**Propósito.** Este mapa define contratos curriculares verificables para que el contenido importado pueda clasificarse por nivel, competencia y objetivo. No es una afirmación de que existan ya 1000 entradas por par.

| Etapa               | Objetivo observable                                                         | Competencias prioritarias                                                 | Contenido requerido                                                        | Evaluación mínima                                                           |
| ------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| A0 (pre-A1 interno) | Reconocer la interfaz, sonidos iniciales, saludos y símbolos básicos        | Orientación, conciencia fonológica, lectura inicial                       | Alfabeto/escritura cuando aplique, saludos, números y rutinas              | Reconocimiento y selección; no se presenta como nivel CEFR oficial          |

| A2                  | Resolver intercambios cotidianos previsibles con cierta autonomía           | Pasado/futuro básico, descripción, comprensión de textos breves           | Rutinas, viajes, salud, trabajo, preferencias y conectores frecuentes      | Comprensión, transformación, respuesta contextual y revisión SRS            |

## Competencias por lección

Cada lección persistida debe declarar una ruta ordenada `sourceLanguage → targetLanguage`, nivel, módulo, objetivo, competencia principal, tema, dificultad, prerrequisitos, fuente/licencia y ejercicios asociados. Las competencias se agrupan en vocabulario, gramática, comprensión lectora, comprensión auditiva, producción oral, pronunciación, escritura e interacción. Una lección puede trabajar varias competencias, pero debe conservar una principal para el progreso y la recomendación.

## Progresión de dominio

La progresión observable es `idioma → dirección → nivel → módulo → lección → concepto → ejercicios → práctica → evaluación → dominio`. El dominio no se deriva de una etiqueta aislada: requiere actividad persistida, resultado de ejercicios y, cuando exista suficiente evidencia, revisión de varias destrezas. Las reglas actuales de nivel por lecciones completadas son un mecanismo provisional de producto y no una certificación CEFR.

## Contrato de ejercicios

El modelo actual cubre `fill_blank`, `matching`, `translation` y `multiple_choice`. Los tipos de escritura, ordenación, detección de errores, transformación, conjugación, lectura, escucha y pronunciación quedan definidos como extensiones de contrato, pero no se activan sin datos, respuestas, explicaciones, evaluación y licencia de audio verificables. Esta decisión evita mostrar una capacidad nominal que no tenga ejecución real.
