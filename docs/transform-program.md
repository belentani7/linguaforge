# Programa de transformación de LinguaForge

## Decisión de alcance

LinguaForge es una plataforma de aprendizaje de idiomas. El texto adjunto `pasted_content_4.txt` contiene, además de peticiones aplicables a LinguaForge, una propuesta completa para **Marcia Job Suite**, con optimización de CV, cartas de presentación, entrevistas sociosanitarias y seguimiento de empleo. Ese bloque describe un producto diferente, con otra audiencia, datos sensibles y otras obligaciones. No se integra en LinguaForge ni se mezcla con las cuentas, currículo, IA o repositorio de la plataforma educativa.

La transformación aplicable se concentra en mejorar la calidad pedagógica, el modelo de escalabilidad, la experiencia de aprendizaje, el asistente IA acotado, la arquitectura de voz y multimedia, la seguridad, la documentación pública, el empaquetado portable y la distribución del repositorio canónico.

## Criterios de aceptación

| Dimensión                  | Evidencia mínima para declarar avance                                                                                | No se aceptará como evidencia                                                                    |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Material didáctico         | Lote de contenido con fuente, licencia, idioma, dirección, nivel, tema, ejemplos, validación y manifiesto            | Texto generado sin procedencia, datos de muestra presentados como curso completo                 |
| IA educativa               | Procedimiento servidor con validación de entrada, límite de coste, controles de seguridad, prueba y aviso de límites | Endpoint cliente directo, agente con permisos de envío/publicación o respuestas sin trazabilidad |
| Voz, imagen y vídeo        | Artefacto con modelo, versión, licencia, consentimiento cuando aplique, hash y revisión                              | Repositorio de código sin verificar pesos, voces, datasets y licencia de salida                  |
| Escalabilidad              | Presupuesto de datos, índices, paginación, límites, observabilidad y rollback                                        | Promesas de «capacidad máxima» sin tráfico o costes medidos                                      |
| Seguridad y privacidad     | Autorización por usuario, secretos solo de servidor, inventario de datos y revisión legal pendiente visible          | Activar correo, analítica o multimedia sin proveedor, permiso y política aprobada                |
| Open source y portabilidad | README, licencia, atribución, scripts reproducibles, ZIP verificado y árbol sin secretos                             | Copiar dependencias, archivos temporales o credenciales al repositorio/ZIP                       |

## Orden de ejecución

Primero se completa una auditoría comparable y una arquitectura de escalabilidad. Después se aplican únicamente mejoras de producto que puedan probarse con el stack actual. El contenido masivo, la voz natural, el vídeo, el audio de pronunciación y las integraciones externas se implementarán solo después de superar los gates de licencia, datos, costes, consentimiento y revisión humana ya documentados.

> La meta es elevar la utilidad y la calidad verificable de LinguaForge. No se declarará que es «la mejor plataforma del mundo» ni que está «100% completa» hasta contar con evidencia pública, contenido real, revisión pedagógica y operación sostenida.
