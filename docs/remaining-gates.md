Este documento evita confundir preparación técnica con ejecución real. Las tareas marcadas como bloqueadas no se consideran fallos del código; requieren datos, decisiones, aprobación profesional o una acción manual fuera del agente.

## Regla de seguridad

La orden maestra añade búsqueda y un mapa curricular documentado. `content.search` consulta únicamente vocabulario, ejemplos, módulos y lecciones existentes, muestra un estado vacío honesto y conserva licencia/procedencia. Los conceptos gramaticales, diccionario ampliado, audio, pronunciación, listening y speaking siguen bloqueados hasta que existan modelo de datos, datos licenciados, evaluación y pruebas.

Ningún modelo de voz, imagen, vídeo o IA se incorpora al runtime público solo porque su repositorio tenga una licencia permisiva. Antes de cada integración se deben verificar por separado el código, los pesos, las voces, los datasets, los plugins, el consentimiento, el tamaño, el coste, la seguridad y la política de retirada.

El asistente IA actual no conserva prompts ni respuestas en la tabla de cuota; solamente registra el identificador del usuario, idioma objetivo, tarea, longitud, modelo y fecha. Este límite no autoriza el uso autónomo: la herramienta no publica contenido, no envía comunicaciones, no procesa pagos, no realiza diagnósticos clínicos ni certifica niveles.
