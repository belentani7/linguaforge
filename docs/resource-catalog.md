# Catálogo escalable de recursos

LinguaForge no afirma disponer de una cifra fija de herramientas hasta contar con un inventario verificable. El catálogo crecerá por módulos y cada recurso deberá registrar identificador, función, idioma, nivel, licencia, fuente, versión, responsable de mantenimiento, fecha de revisión y estado (`propuesto`, `revisado`, `publicado`, `retirado`).

Los recursos se agrupan en contenido lingüístico, ejercicios, audio, vídeo, voz, utilidades de autoría, analítica y gobierno operativo. La incorporación requiere revisar derechos, privacidad, seguridad, accesibilidad, coste y compatibilidad con la arquitectura. Los recursos sin licencia clara, con consentimiento incompleto o sin responsable de mantenimiento permanecen fuera de producción.

El crecimiento se mide por recursos publicados y mantenidos, no por una cifra promocional. Cada versión debe conservar un changelog y una ruta de reversión. El inventario podrá ampliarse mediante contribuciones open source, pero las propuestas externas necesitan revisión antes de integrarse en el producto.

## Validación mínima

Antes de publicar un recurso se debe confirmar:

| Control | Evidencia |
|---|---|
| Procedencia | Fuente y versión registradas |
| Derechos | Licencia o consentimiento verificable |
| Calidad | Revisión lingüística y funcional |
| Seguridad | Sin secretos, malware ni datos innecesarios |
| Accesibilidad | Texto alternativo, subtítulos o controles equivalentes |
| Mantenimiento | Responsable y fecha de próxima revisión |
