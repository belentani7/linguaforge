# Privacy Policy

## Data We Collect
- Anonymous UUID for progress tracking (localStorage only)
- Voluntary feedback submissions (no PII required)

## Data We Don't Collect
- Personal identification (name, email, DNI/NIF)
- Usage analytics or tracking
- Third-party cookies
- IP addresses or device fingerprints

## AI Interaction
- User content is never stored beyond session
- PII is stripped before sending to LLM providers
- No training data is collected from user inputs

## Retention
- Session data: deleted on tab close
- Logs: retained for 30 days, no PII
- No persistent user profiles

## Rights (GDPR)
You have the right to:
- Access your data
- Rectification
- Erasure ("right to be forgotten")
- Data portability
- Object to processing
